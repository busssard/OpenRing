* Turning the phone while Setup pairs the ring no longer loses the result: the key page shows on the new screen, and after the app was closed it shows on the next start.
* A new key is saved on the phone before it is written to the ring. If pairing stops halfway, Setup shows that key, and "Pair and create a new key" uses it again, so the ring is no longer locked out.
* A lost connection after the key was saved no longer counts as a failed pairing.
