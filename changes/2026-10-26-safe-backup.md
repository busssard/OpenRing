* A full backup and Export database now make a checked copy of your history first, so a sync or analysis running at the same moment can no longer leave a backup with missing or damaged parts. If the copy does not pass its check, nothing is saved and the app says so.
* Restoring a backup now refuses a history that lacks any part the app needs, with "The history in this backup is damaged, nothing was changed." Your history on the phone stays.
* A backup now also keeps the sleep stage detail setting and the ring finder sound switch.
* A key file saved with Windows Notepad (it starts with an invisible mark) is accepted, and a damaged or cut off file says so in a plain sentence.
* Restored settings stay inside what Settings allows (for example no negative screen time goal).
