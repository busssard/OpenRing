* Saving a backup or export and Re analyse all keep running when you turn the phone or leave Settings, show a line while they run, and cannot be started twice by accident.
* A backup that fails on the way no longer leaves a cut off file that looks like a backup: the file is removed, or the message says it is incomplete.
* A full backup is saved about twice as fast (the file is about a tenth larger).
* While this phone cannot read the saved ring key, backups (also the automatic ones) are still saved, without the key. After restoring such a backup, enter your key in Setup. A key already on the phone is never replaced by it.
